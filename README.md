# thecraftsymphony.com: landing page

A single-page site for GitHub Pages, built from The Craft Symphony brand guide.

## Publish
1. Open the website's GitHub repository.
2. Replace the old "coming soon" files with everything in this folder. **Keep `CNAME`**
   (this folder includes one with `www.thecraftsymphony.com`).
3. Commit. The site updates in 1–2 minutes.

## Files
- `index.html`: the page; all styles are inside it.
- `assets/`: logo files cut from the brand guide (colour, white and with tagline),
  favicon and the image shown when the link is shared on social media.

## Notes
- Fonts: the brand font, Clifford Eighteen, is a paid font, so the page uses EB Garamond
  (a free classic serif) for headings and Quicksand for text. The logo images keep the
  real brand lettering. If you buy a Clifford Eighteen web licence, it can be swapped in.
- "Email us for updates" opens an email to info@aaththi.com. For a real sign-up form,
  connect a free mailing-list service such as Mailchimp or Formspree.
